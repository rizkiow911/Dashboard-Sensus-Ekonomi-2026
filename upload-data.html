Unggah file Excel (.xlsx) dengan kolom persis sama dengan tab Google Sheet tujuan. File divalidasi dulu di browser sebelum dikirim — data lama di tab tujuan akan digantikan seluruhnya oleh isi file ini.

Belum tersambung ke Google Sheet. uploadEndpoint di shared/shared-config.js masih kosong — artinya belum ada Apps Script Web App yang dideploy. Kamu tetap bisa mencoba unggah & validasi file di bawah (mode pratinjau), tapi tombol "Kirim ke Google Sheet" baru aktif setelah endpoint diisi. Lihat PANDUAN_UPLOAD.md di paket file untuk langkah deploy Apps Script-nya.
Cara kerja & peringatan penting: mode tulis di sini memakai pola "replace" — Apps Script akan mengosongkan semua baris di tab tujuan (kecuali header) lalu menulis ulang seluruh baris dari file yang kamu unggah. Untuk uji coba pertama kali, sangat disarankan duplikat tab Sheet1 menjadi tab baru (mis. Sheet1 (Test)) di Google Sheet, lalu isi kolom "Nama tab tujuan" di bawah dengan nama tab duplikat itu — baru arahkan ke Sheet1 yang asli setelah kamu yakin alurnya benar.
