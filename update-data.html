Update Data

Sejak migrasi ke Supabase, dashboard ini tidak lagi punya jalur unggah Excel dari halaman ini — data mentah diperbarui langsung di sisi Supabase. Halaman ini menampilkan kondisi data terkini dan riwayat update secara read-only.

Yang berubah dari cara lama: menu ini dulu bernama "Upload Data Terbaru" — kamu unggah file Excel, dashboard memvalidasi kolomnya, lalu mengirimkannya ke Google Sheet lewat Apps Script (mode "replace" seluruh tab). Alur itu sudah tidak berlaku sejak sumber data pindah ke Supabase. Update data sekarang dilakukan langsung di Supabase — lewat Table Editor (impor CSV/manual), SQL Editor, atau script impor terpisah yang kamu jalankan sendiri (mis. dari FASIH-SM/Dashboard SE2026) — bukan lagi lewat dashboard ini.
dataSource bukan "supabase". Halaman ini hanya membaca dari Supabase (tidak ada padanan di Google Sheets lama) — ganti dataSource di shared/shared-config.js menjadi "supabase" untuk mengaktifkan halaman ini.

Cara mencatat update baru

Setiap kali kamu selesai memperbarui data mentah di Supabase, jalankan query berikut di SQL Editor Supabase supaya tercatat di riwayat pada halaman ini:

  1. Perbarui data seperti biasa (Table Editor, impor CSV, atau script sinkron kamu).
  2. Buka SQL Editor di dashboard Supabase project kamu.
  3. Jalankan query ini, ganti nilai sesuai keadaan sebenarnya:
insert into public.data_sync_log (table_name, source_label, row_count, status, note, synced_by) values ('sls_data', 'FASIH-SM & Dashboard SE2026', 9700, 'success', 'Update rutin harian', 'Nama kamu');

Baris ini langsung muncul di riwayat pada refresh berikutnya (maks 45 detik). Kalau tabel data_sync_log belum ada sama sekali, jalankan dulu sql/data_sync_log.sql yang disertakan di paket file ini (sekali saja) — file itu juga berisi query INSERT contoh di atas.
